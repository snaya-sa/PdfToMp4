# محول PDF إلى MP4

تطبيق ويب تقدمي (PWA) لتحويل ملفات PDF إلى فيديو MP4 مع إمكانية إضافة صوت.

## المميزات

- **يعمل بدون إنترنت** - بعد الزيارة الأولى، يعمل التطبيق بالكامل بدون اتصال
- **خصوصية تامة** - جميع العمليات تتم على جهازك، لا يتم رفع أي ملفات
- **دعم الصوت** - إضافة صوت من ملفات صوتية أو استخراجه من فيديو
- **تحكم كامل** - ضبط مدة كل صفحة، جودة الفيديو، وعدد الإطارات
- **واجهة عربية** - واجهة مستخدم كاملة باللغة العربية مع دعم RTL

## التقنيات المستخدمة

- **FFmpeg.wasm** - معالجة الفيديو في المتصفح
- **PDF.js** - عرض وتحويل ملفات PDF
- **Vite** - أداة البناء السريعة
- **PWA** - تطبيق ويب تقدمي مع Service Worker

## التشغيل المحلي

```bash
# تثبيت المتطلبات
bun install

# تشغيل خادم التطوير
bun run dev

# بناء الإنتاج
bun run build

# معاينة البناء
bun run preview
```

## الاستخدام

1. **رفع ملف PDF** - اسحب وأفلت أو انقر للاختيار
2. **إضافة صوت (اختياري)** - ملف صوتي (MP3, WAV) أو فيديو (MP4, WebM) لاستخراج الصوت منه
3. **ضبط الإعدادات**:
   - مدة كل صفحة (١-٦٠ ثانية)
   - مطابقة المدة مع الصوت تلقائياً
   - جودة الفيديو (480p, 720p, 1080p)
   - عدد الإطارات (24, 30, 60 fps)
4. **تحويل وتحميل** - انقر على زر التحويل وانتظر ثم حمّل الفيديو

## متطلبات المتصفح

- Chrome 80+
- Firefox 79+
- Safari 14.1+
- Edge 80+

يتطلب التطبيق دعم:
- WebAssembly
- SharedArrayBuffer
- Service Workers
