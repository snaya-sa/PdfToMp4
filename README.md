# محول PDF إلى MP4

تطبيق ويب تقدمي (PWA) لتحويل ملفات PDF إلى فيديو MP4 مع إمكانية إضافة صوت.

[![Deploy to GitHub Pages](https://github.com/snaya-sa/PdfToMp4/actions/workflows/deploy.yml/badge.svg)](https://github.com/snaya-sa/PdfToMp4/actions/workflows/deploy.yml)

## المميزات

- **يعمل بدون إنترنت** - بعد الزيارة الأولى، يعمل التطبيق بالكامل بدون اتصال
- **خصوصية تامة** - جميع العمليات تتم على جهازك، لا يتم رفع أي ملفات
- **دعم الصوت** - إضافة صوت من ملفات صوتية أو استخراجه من فيديو
- **الصوت من الروابط** - استخراج الصوت من الروابط العامة في YouTube وTikTok وX وInstagram وغيرها عند التشغيل بخادم التطبيق
- **تكرار العرض** - إعادة تسلسل صفحات PDF من ١ إلى ١٠٠ مرة دون تكرار الصور في الذاكرة
- **تحكم كامل** - ضبط مدة كل صفحة، جودة الفيديو، وعدد الإطارات
- **واجهة عربية** - واجهة مستخدم كاملة باللغة العربية مع دعم RTL

## التقنيات المستخدمة

- **FFmpeg.wasm** - معالجة الفيديو في المتصفح
- **PDF.js** - عرض وتحويل ملفات PDF
- **Vite** - أداة البناء السريعة
- **PWA** - تطبيق ويب تقدمي مع Service Worker

## التشغيل المحلي

يتطلب خيار استخراج الصوت من الروابط تثبيت `yt-dlp` و`ffmpeg` على الجهاز الذي يشغّل الخادم. أما رفع الملفات والتحويل فلا يحتاجان ذلك.

```bash
# تثبيت المتطلبات
bun install

# تشغيل خادم التطوير
bun run dev

# بناء الإنتاج
bun run build

# معاينة البناء
bun run preview
```

> ملاحظة: GitHub Pages يستضيف ملفات ثابتة فقط، لذلك خيار الروابط يحتاج خادمًا يدعم المسار `/api/media-audio`. يعمل المسار تلقائيًا مع `bun run dev` و`bun run preview` في هذا المستودع.

## الاستخدام

1. **رفع ملف PDF** - اسحب وأفلت أو انقر للاختيار
2. **إضافة صوت (اختياري)** - ملف صوتي، فيديو، أو رابط مقطع عام لاستخراج الصوت منه
3. **ضبط الإعدادات**:
   - مدة كل صفحة (١-٦٠ ثانية)
   - عدد مرات تكرار العرض (١-١٠٠ مرة)
   - مطابقة المدة مع الصوت تلقائياً
   - جودة الفيديو (480p, 720p, 1080p)
   - عدد الإطارات (24, 30, 60 fps)
4. **تحويل وتحميل** - انقر على زر التحويل وانتظر ثم حمّل الفيديو

## متطلبات المتصفح
